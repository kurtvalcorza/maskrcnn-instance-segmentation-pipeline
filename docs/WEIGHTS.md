# Weight provenance and hosting

- Upstream: `torchvision/maskrcnn_resnet50_fpn_v2`, meaning torchvision's `maskrcnn_resnet50_fpn_v2` builder with `MaskRCNN_ResNet50_FPN_V2_Weights.COCO_V1`. This identifier names the torchvision weights; it is not a Hugging Face Hub repository.
- Revision: **not yet pinned** (`MODEL_REVISION = "unpinned"`). A file served from a URL has no commit, so the pinned revision is the SHA-256 of the checkpoint's bytes. Run `python tools/pin_snapshot.py` to download the file, check that its SHA-256 starts with `73cbd019` (the prefix torchvision puts in the file name), strict-load it into the architecture, and write the digest and byte size into the manifest and `src/maskrcnn_instance_segmentation_pipeline/pipeline.py`.
- Source URL: `https://download.pytorch.org/models/maskrcnn_resnet50_fpn_v2_coco-73cbd019.pth`, the `url` of the weights enum in the pinned `torchvision==0.29.0`; a test asserts the two agree.
- Weight format: a PyTorch `state_dict` saved with `torch.save` (`.pth`, a zip archive holding pickled tensor metadata). torchvision's weight metadata lists its size as 177.219 MB; the exact byte count is recorded only when the pin tool runs.
- Manifest: `weights/maskrcnn-resnet50-fpn-v2/dimer-base-manifest.json`, format `dimer_url_snapshot`, one entry with `path`, `url`, `bytes` and `sha256`. `bytes`, `sha256` and `totalBytes` are `null` until the pin tool runs.
- Upstream licence: torchvision's code is BSD-3-Clause. torchvision's README states that its pre-trained models may have their own licences or terms derived from the dataset used for training, and that the user must determine whether they have permission to use a model for their use case. The weights were fitted to COCO, whose annotations are CC BY 4.0 and whose images remain under their Flickr licences.
- Hosting: the Git repository does not vendor the checkpoint (`weights/**/*.pth` is git-ignored). A fresh clone stages it from the URL above.
- Fresh clone, once pinned: `stage_missing_files(allow_download=True)` fetches the file only if it is absent, only from the manifest URL, and only if that URL equals the package's `WEIGHTS_URL`; `torch.hub.download_url_to_file` checks the file-name prefix during the download, and `verify_snapshot()` then checks the full SHA-256 and the byte size before any load.
- Loader trust boundary: `maskrcnn_resnet50_fpn_v2(weights=None, weights_backbone=None, num_classes=91)` builds the architecture without downloading anything, and `torch.load(<verified file>, map_location="cpu", weights_only=True)` restricts unpickling to tensors and plain containers. `load_state_dict(strict=True)` refuses a missing, unexpected or mis-shaped tensor.
